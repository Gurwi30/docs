---
title: Confetti
description: A lightweight YAML configuration library for Java, built on top of SnakeYAML.
---

Confetti is a lightweight YAML configuration library for Java that provides a simple API for loading, reading, modifying, and saving YAML configuration files.

It supports filesystem configurations, classpath resources, annotation-based configuration, typed accessors, runtime reloading, default resources, and custom serialization.
