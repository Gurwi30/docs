## Requirements

Confetti requires:

* Java 21 or newer
* SnakeYAML 2.4

## Installation

Confetti is available on Maven Central.

<Tabs items={['Maven', 'Gradle (Groovy)', 'Gradle (Kotlin)']}>
<Tab value="Maven">
Add the dependency to your `pom.xml`.

```xml
<dependency>
    <groupId>dev.gurwi</groupId>
    <artifactId>confetti</artifactId>
    <version>0.1.5</version>
</dependency>
```
</Tab>

<Tab value="Gradle (Groovy)">
Add the dependency to your `build.gradle`.

```groovy
repositories {
    mavenCentral()
}

dependencies {
    implementation "dev.gurwi:confetti:0.1.5"
}
```
</Tab>

<Tab value="Gradle (Kotlin)">
Add the dependency to your `build.gradle.kts`.

```kotlin
repositories {
    mavenCentral()
}

dependencies {
    implementation("dev.gurwi:confetti:0.1.5")
}
```
</Tab>
</Tabs>

## Building from Source

If you want to build Confetti directly from the source repository:

```bash
git clone https://github.com/Gurwi30/confetti.git
cd confetti
./gradlew build
```

On Windows:

```powershell
git clone https://github.com/Gurwi30/confetti.git
cd confetti
.\gradlew.bat build
```

## Your First Configuration

Create `config.yml`:

```yaml
server:
  host: localhost
  port: 8080

database:
  enabled: true
```

Load it from a file:

```java
import dev.gurwi.confetti.Confetti;
import dev.gurwi.confetti.configuration.base.Configuration;

Confetti confetti = new Confetti();

Configuration config = confetti
        .fromFile("config.yml")
        .load();

String host = config.getString("server.host");
Integer port = config.getInt("server.port");
Boolean enabled = config.getBool("database.enabled");
```

## Classpath Resources

For bundled read-only YAML files, place the resource in `src/main/resources`:

```text
src/
└── main/
    └── resources/
        └── defaults.yml
```

Load it directly:

```java
Configuration config = confetti
        .fromResource("defaults.yml")
        .load();
```

Or use `@ResourceConfig` for annotation-based configuration:

```java
@ResourceConfig("defaults.yml")
public class Defaults {

    @Path("server.host")
    public static String HOST;

    @Path("server.port")
    public static Integer PORT;
}
```

Then load the class:

```java
confetti.load(Defaults.class);
```

`@ResourceConfig` configurations are read-only and are intended for configuration bundled with the application.
