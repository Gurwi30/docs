---
title: Commands and Permissions
description: Full list of InventoryTracker commands and their required permissions.
---

| Command                             | Description                              | Permission                             |
| ------------------------------------ | ------------------------------------------ | ----------------------------------------- |
| `/invtracker restore [target]`      | Restore a player inventory               | `inventorytracker.command.restore`     |
| `/invtracker forcebackup <target>`  | Force save a player inventory            | `inventorytracker.command.forcebackup` |
| `/invtracker clear <target>`        | Clears the target logs                   | `inventorytracker.command.clear`       |
| `/invtracker bulkupdate`            | Update big amounts of data               | CONSOLE ONLY                           |
| `/invtracker info`                  | Get more information about the plugin    |                                         |
| `/invtracker reload`                | Reload the plugin configuration          | `inventorytracker.command.reload`      |
