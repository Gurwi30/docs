## Project structure

```
prism
├── core/                  Platform-agnostic command model
├── reflection/            Small reflection helpers shared across platform modules
├── platform/
│   ├── bukkit/            Shared Bukkit API layer
│   ├── spigot/            Spigot platform and registry
│   ├── paper/             Paper platform and registry
│   ├── velocity/          Velocity platform and registry
│   ├── bungeecord/        BungeeCord platform and registry
│   └── jda/               Discord (JDA) platform, in development
├── brigadier/
│   ├── brigadier-api/     Platform-independent Brigadier builder and adapter
│   ├── brigadier-minecraft/  Minecraft-facing Brigadier bridge
│   ├── brigadier-paper/   Paper-native adapter
│   └── nms/               V1_13 … V1_21 and V26 adapters
├── bundles/
│   ├── paper-bundle/      Aggregates modules into the prism-paper bundle
│   └── spigot-bundle/     Aggregates modules into the prism-spigot bundle
├── build-logic/
│   └── spigot-nms/        Gradle plugin for Spigot NMS reobfuscation
├── buildSrc/              Shared publishing conventions
├── plugin/
│   └── bukkit-plugin/     Standalone Prism plugin
└── examples/
    ├── paper-plugin/      Paper example plugin
    ├── velocity-plugin/   Velocity example plugin
    └── bungeecord-plugin/ BungeeCord example plugin
```

## Requirements

- A JDK that Gradle can use for toolchains. Gradle's toolchain resolver can download missing JDKs.
- Gradle itself must run on JDK 25 or newer while the Velocity module is part of the build.
- No separate Gradle install: use the wrapper.

| Part                                               | Java |
|----------------------------------------------------|------|
| Library (core, Bukkit layer, Spigot/Paper)         | 11   |
| BungeeCord platform                                | 17   |
| `V1_13` – `V1_17` adapters                         | 16   |
| `V1_18`, `V1_19` adapters                          | 17   |
| `V1_20`, `V1_21` adapters                          | 21   |
| `V26` and `brigadier-paper` adapters               | 25   |
| Velocity platform                                  | 25   |
| Unit tests                                         | 21   |
| CI (`./gradlew test`), Paper and Velocity examples | 25   |
| BungeeCord example                                 | 21   |

Each version adapter is compiled against its own Spigot version (and `brigadier-paper` against the Paper 26.3 dev bundle). The `spigot-nms` Gradle plugin in `build-logic/` handles Spigot NMS reobfuscation for those modules.

## Modules and bundles

| Artifact           | Contains                                                                                               |
|--------------------|--------------------------------------------------------------------------------------------------------|
| `prism-spigot`     | core, Bukkit layer, Spigot platform, Brigadier layer and all version adapters except `brigadier-paper` |
| `prism-paper`      | core, Bukkit layer, Paper platform, Brigadier layer and the Paper adapter (plus the version adapters)  |
| `prism-velocity`   | Velocity platform. Depends on `prism-core` and `prism-brigadier-api`                                   |
| `prism-bungeecord` | BungeeCord platform. Depends on `prism-core` and `prism-brigadier-api`                                 |

`prism-core`, `prism-bukkit`, `prism-brigadier-api` and `prism-brigadier-minecraft` are published on their own too. Published coordinates use the group `dev.gurwi` and the `prism-…` artifact IDs.

## Build and test

```bash
git clone https://github.com/AthlasStudios/prism.git
cd prism

# Compile everything and build the jars
./gradlew build

# Run the test suite
./gradlew test
```

On Windows, use `gradlew.bat`. Tests use JUnit with MockBukkit (`mockbukkit-v1.21`), so automated coverage targets a mocked 1.21 server.

## Trying it on a server

The `examples/paper-plugin` module exercises most of the API (subcommands, argument trees, flags, async and sync suggestions and many built-in arguments).

```bash
# Start a local Paper server with the example plugin
./gradlew :examples:paper-plugin:runServer

# Or just build the plugin jar
./gradlew :examples:paper-plugin:shadowJar
```

Its source, [`PaperExample.java`](https://github.com/AthlasStudios/prism/blob/main/examples/paper-plugin/src/main/java/dev/gurwi/prism/example/paper/plugin/PaperExample.java), doubles as a set of usage examples.

For the proxies, each example is a minimal plugin that registers one command:

```bash
# Local Velocity proxy
./gradlew :examples:velocity-plugin:runVelocity

# Local Waterfall proxy
./gradlew :examples:bungeecord-plugin:runWaterfall
```

## Contributing

1. [Open an issue](https://github.com/AthlasStudios/prism/issues) to discuss larger changes.
2. Fork the repository and branch from `main`.
3. Make your change and add or update tests.
4. Run `./gradlew test`; CI runs the same check on every push and pull request.
5. Open a pull request describing what changed and why.
