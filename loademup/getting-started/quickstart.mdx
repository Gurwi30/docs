## ➕ Install

1. **Download**
   Get the latest LoadEmUp `.jar` from the official [Modrinth page](https://modrinth.com/plugin/loademup).
2. **Add to Server**
   Place the downloaded `.jar` file into your server's `plugins` folder.
3. **Start Your Server**
   Restart your server for the plugin to load properly. You can also reload plugins, but a full restart is recommended.
4. **Enjoy**
   Stop worrying about plugin reloads and focus on developing and managing your server smoothly with LoadEmUp!
